# 뉴 슈퍼 마리오브라더스 2 골드 에디션 한국판 800×240 패치

**v0.9 베타** · Luma3DS `code.ips` 패치

3D 슬라이더를 끄면 상단 화면을 **800×240 2D**로 출력하고, 켜면 **원래 400×240 입체 출력(한쪽 눈 기준)**으로 전환하는 패치입니다. 하단 화면은 기존 320×240 표시를 유지합니다.

텍스처팩이나 세로 해상도를 높이는 패치가 아닙니다. 3DS 상단 화면에서 3D용으로 나누어 쓰는 가로 800개의 화소를 2D 한 화면에 활용합니다. 화면 비율은 유지하며 가로 방향의 표현을 더 세밀하게 만듭니다. 3D를 켠 상태에서 800×240을 양쪽 눈에 각각 출력하는 기능은 아닙니다.

## 대상과 동작

| 항목 | 내용 |
|---|---|
| 게임 | 뉴 슈퍼 마리오브라더스 2 **골드 에디션 한국판** |
| 타이틀 ID | `0004000000143300` |
| 제품 코드 | `CTR-P-BMAK` |
| 슬라이더 OFF | 상단 800×240 2D |
| 슬라이더 ON | 상단 400×240/눈, 기존 3D 출력 |
| 하단 | 기존 320×240 표시 |
| 배포 형식 | Luma3DS `code.ips` |

일반판·다른 지역판용 패치가 아닙니다. 실행파일의 특정 배치를 기준으로 제작했으며, 타이틀 ID가 같아도 다른 업데이트·실행파일 조합의 호환성이 보장되는 것은 아닙니다. 다른 기종·Luma 버전·업데이트 조합과 에뮬레이터는 별도 검증하지 않았습니다.

## 설치

1. Releases에서 `NSMB2_KR_Gold_800x240_v0.9.zip`을 다운로드합니다.
2. 게임을 완전히 종료합니다. 같은 위치에 기존 `code.ips`가 있으면 별도로 백업합니다.
3. ZIP 안의 `luma` 폴더를 SD 카드 최상위에 복사합니다.
4. 최종 경로가 다음과 같은지 확인합니다.

   ```text
   SD:/luma/titles/0004000000143300/code.ips
   ```

5. 본체 전원을 끈 뒤 SELECT를 누르면서 켜서 Luma3DS 설정을 엽니다.
6. **Enable game patching**을 켜고 START로 저장합니다.
7. 게임을 실행하고 3D 슬라이더를 완전히 내린 상태와 올린 상태를 확인합니다.

일반 설치에는 소스 빌드나 메모리 덤프가 필요하지 않습니다. 다른 `code.ips`와 자동으로 합쳐지지 않습니다. 기존 패치와 함께 사용하려면 수정 위치의 충돌을 확인한 별도 병합이 필요합니다.

### 제거

게임을 완전히 종료하고 위 경로의 `code.ips`를 삭제하거나 백업해 둔 기존 파일로 복원합니다.

## 확인 범위

제작자 테스트 환경에서 기본 진행·화면 표시·2D/3D 전환이 정상이라는 실기 피드백을 받았습니다. 다만 장시간 플레이, 모든 코스·모드, HOME·슬립 복귀, 다른 기기·업데이트 조합까지 검증한 완성판은 아니므로 **v0.9 베타**로 공개합니다. 테스트 기기 모델·Luma 버전·게임 업데이트 조합의 상세 목록은 아직 정리되지 않았습니다.

공개판 v0.9는 정상 동작 피드백을 받은 **개발판 v0.3과 동일한 IPS**입니다. 공개용 이름과 문서를 정리했으며 새 기능이나 추가 코드 변경은 없습니다.

공개용 소스로 다시 빌드해 기준 IPS와 동일한 결과를 확인했습니다. CPU 분리 실행 검사에서는 모드 전환·실제 프레임 호출 경로·UI·LCD 전송·RAM 할당/해제를 확인했습니다. 이 검사는 합성 서비스·힙을 사용하므로 전체 게임·GPU·실기 장시간 테스트를 대신하지 않습니다. 최종 v0.3/v0.9의 OFF/ON 덤프 한 쌍을 통한 수치 대조는 아직 하지 않았습니다.

## 자주 묻는 질문

**3D를 켜면 배경이 흐려집니다.**

뉴슈마2에는 원래 슬라이더와 연동되는 배경 흐림 효과가 있습니다. 배경이 흐려지는 것만으로 3D 전환 성공 여부를 판단할 수는 없습니다. 캐릭터·지형의 입체감도 함께 확인해 주세요. 이 패치는 슬라이더 OFF에서 800 2D, ON에서 원래 3D 출력으로 전환하도록 제작했습니다.

**‘코스를 나가기’가 비활성화되어 있습니다.**

아직 클리어하지 않은 코스에서 나가기 메뉴가 비활성화되는 것은 원래 게임의 동작입니다. 이미 클리어한 코스에서 확인해 주세요.

**검은 화면이나 진행 정지가 발생합니다.**

게임을 완전히 종료하고 이 패치를 제거한 상태에서도 같은 증상이 있는지 비교해 주세요. 보고할 때는 기기 모델, Luma 버전, 타이틀 ID·업데이트, 다른 패치 유무, 발생 코스·행동, 슬라이더 위치를 함께 적어 주세요.
